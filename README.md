# 萌萌幻奏 · Mistbound Chronicle

《萌萌幻奏》是一款浏览器策略游戏，你可以在六角地图上治理领地、招募同伴，并组建军队参与战棋对局。 游戏已随包提供普通版全部 1400 张图片，包含 1344 张角色立绘以及封面、场景和建筑图，开局无需额外下载素材。

[下载普通版完整游戏](https://github.com/3121455692atou-sudo/mistbound-chronicle/releases/latest) · [附加图包导入教程](docs/ART-PACK.md)

## 本地游玩

请前往 GitHub Releases 下载以 Mistbound-Game 开头的 ZIP 压缩包，并将其完整解压到任意文件夹中。

请先安装 Node.js 22.13 或更高版本，然后在解压后的游戏目录中打开终端，运行 `npm start` 启动游戏。

在浏览器中访问下一行给出的本机网址即可进入游戏，游玩期间请保持运行命令的终端处于打开状态。

`http://127.0.0.1:4173/`

作为补充方法，如果已有 Python 3，也可以在游戏根目录运行下一行命令，再通过相同网址打开游戏。

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

单机可直接在本地游玩，联机房间、Discord 登录和云存档则需要另行配置服务。

## 项目结构与验证

- `dist/` 是可直接托管的普通版站点，包含游戏源码、地图、对话、全部普通图片、字体和图包读取器。
- `tools/cli.mjs` 提供单机规则的命令行入口，可执行 `node tools/cli.mjs help`。`examples/` 和 `schemas/` 提供样例和模组格式。
- `account/` 是 Discord 登录与云存档服务。`multiplayer/server/` 是联机房间服务，`multiplayer/web/` 保留服务端所用的规则版本。[自托管说明](docs/HOSTING.md)
- `npm run test:release` 运行图包、存储、账户、联机、领水与财务等发布检查。`npm test` 运行开发版原有的当前策略测试入口，包含若干已知的历史规则断言失败。运行测试需要 Node.js 22.13 以上，部分账户工具测试还使用 Python 3。
